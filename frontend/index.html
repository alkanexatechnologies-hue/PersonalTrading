Groww Connection

MARKET DATA SOURCE  🟢 GROWW single source
Saved token: — — stored server-side, never shown in full

The access token is the only Groww credential this app needs. Generate it on Groww → Settings → Trading APIs (needs an active Trading API subscription), paste it above and press SAVE ACCESS TOKEN — it is only accepted after a real Groww request succeeds, and is then stored securely server-side (owner-only .groww_token), so it persists across restarts. The full token is never shown, logged, or sent back to this screen. Tokens expire daily ~6 AM IST — paste a fresh one when the test fails.

Login notifications

Dashboard credentials stay the same across restarts and only rotate automatically once a day at 08:00 IST — set an email here to have each new password sent to you instead of checking the server console. Requires the server's SMTP env vars (SMTP_HOST/SMTP_USER/SMTP_PASS) to actually be configured.

Telegram alerts

Setup: create a bot with @BotFather → create a Telegram group → add the bot to the group → paste the bot token and the group's chat ID here. A phone number cannot be used — the Telegram Bot API addresses a destination only by numeric chat ID, and a bot can neither message someone first nor look anyone up by phone. To find the chat ID, add @RawDataBot to the group briefly and read the chat.id it prints, then remove it.

Adding a member: use "Create group invite link" above (the bot must be a group admin with the invite-users right), then send that link to the person — they join themselves. The Bot API has no method to add someone to a group directly.

Credentials may also be supplied as server env vars TELEGRAM_BOT_TOKEN and TELEGRAM_CHAT_ID instead of this form.

Connect Dhan (Historical data — backtesting only)

Used ONLY for pulling historical candles for offline backtesting/research — Groww remains the sole source for OI, EMA, live signals and every trading decision. Dhan tokens expire every 24h; press SAVE again with a fresh one when TEST CONNECTION fails.
